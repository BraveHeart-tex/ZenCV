## Commits and pull requests

Use Conventional Commits:

`<type>(<scope>): <imperative summary>`

Examples:

- `feat(backup): add manual Google Drive backup`
- `fix(backup): reconcile interrupted upload`
- `refactor(database): expose shared initialization`

Reference the active issue in commit footers:

`Refs #87`

Close the implementation ticket from the pull request body:

`Closes #87`
`Part of #86`

Do not close parent specification issues from implementation commits or pull requests.
