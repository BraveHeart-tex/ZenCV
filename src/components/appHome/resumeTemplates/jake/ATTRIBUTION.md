# Jake's Template

Original React PDF implementation for ZenCV, visually inspired by
[Jake's Resume (Anonymous)](https://www.overleaf.com/latex/templates/jakes-resume-anonymous/cstpnrbkhndn),
credited by Overleaf to Anonymous and Jake Gutierrez. Adaptations: A4 instead of
US Letter, bundled Times New Roman, original vector contact icons, and ZenCV's
existing section model and pagination. No LaTeX source or sample resume content
is included in this implementation.
